# ros2_basic

ROS 2 Jazzy와 turtlesim으로 배우는 초보자용 실습 저장소입니다.

## 브랜치

- `main`: 학생 실습 파일만 제공
- `solutions`: 학생 실습, 완성 코드, Launch, config, Challenge 제공

학생용:

```bash
git clone --branch main --single-branch \
  https://github.com/halonaK/ros2_basic.git
```

완성본 참고용:

```bash
git clone --branch solutions --single-branch \
  https://github.com/halonaK/ros2_basic.git ros2_basic_solutions
```

패키지 설명은 [`turtle_robot/README.md`](turtle_robot/README.md)를 참고하세요.
